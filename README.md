# nishadsinghi.github.io

Personal site for Nishad Singhi — static HTML / CSS / JS, served by GitHub Pages.

- `index.html`, `publications.html`, `news.html` — pages
- `css/`, `js/`, `assets/` — styles, scripts, and media
- `vegas/` — project page for the VeGAS paper
- `.github/workflows/deploy.yml` — publishes the repo root to `gh-pages`

Previous versions of the site are preserved on other branches:
- `archive-alfolio` — the prior al-folio Jekyll site
- `redesign` — work-in-progress drafts (notebook + editorial alternatives)
